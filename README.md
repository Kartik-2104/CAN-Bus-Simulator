# CAN Bus Protocol Simulator & Analyzer

A software-only C++ simulation of a simplified automotive CAN network.

## Features

- Object-oriented C++ design
- Virtual Engine, ABS and Dashboard ECUs
- Classical CAN-style data frames
- 11-bit CAN identifiers
- DLC and hexadecimal data bytes
- Dynamic sensor values
- CAN arbitration based on identifier priority
- Bit-by-bit arbitration demonstration
- CAN traffic logging
- CAN ID filtering
- Bus statistics
- Terminal-based visual dashboard
- No external libraries required

## Build on Windows

Open the VS Code terminal in this folder:

```bash
g++ -std=c++17 main.cpp CANFrame.cpp ECU.cpp CANBus.cpp CANAnalyzer.cpp -o can_simulator.exe
```

Run:

```bash
.\can_simulator.exe
```

## Build on Linux/macOS

```bash
g++ -std=c++17 main.cpp CANFrame.cpp ECU.cpp CANBus.cpp CANAnalyzer.cpp -o can_simulator
./can_simulator
```

## Simulated network

| ECU | CAN ID | Simulated signal |
|---|---:|---|
| Dashboard ECU | 0x080 | Coolant temperature |
| Engine ECU | 0x100 | Engine RPM |
| ABS ECU | 0x200 | Vehicle speed |

Lower CAN ID means higher arbitration priority in the simplified standard-ID model.

## Important note

This is a **protocol simulator**, not a physical CAN interface. It models CAN logic in software. The voltage levels, CAN-H/CAN-L transceiver operation and 120-ohm physical termination are discussed as real CAN concepts but are not electrically generated by the program.
